There shouldn't be anything that needs to be set up before testing.

I used this [lightsaber ignition sound](https://pixabay.com/sound-effects/film-special-effects-lightsaber-ignition-6816/), [power off sound](https://pixabay.com/sound-effects/film-special-effects-power-off-386180/), and this [skybox](https://assetstore.unity.com/packages/2d/textures-materials/sky/starfield-skybox-92717).

The base color changes randomly from a pool of 7, but you can add more colors and change them in the Saber Colors array in the Lightsaber script's Inspector on SaberBase. 

A recording of the game footage can be found in the Recordings folder.
